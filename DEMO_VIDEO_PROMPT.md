# AI Demo Video Prompt

Use this script in an AI video generator or screen-recording workflow to create a short product demo.

## Video Goal
Show the Task Tracker app as a clean full-stack mobile app with signup, login, task management, filters, and attachments.

## Length
60 to 90 seconds

## Style
Modern product demo, bright UI, smooth transitions, clear captions, no voiceover required but optional upbeat voiceover works well.

## Scene Breakdown

1. Opening title
   - Visual: App name on screen with a quick animated intro.
   - Text: "Task Tracker App"
   - Subtext: "Full-stack mobile task manager"

2. Signup and login
   - Visual: Show the signup screen, then transition to login.
   - Text: "Create an account in seconds"
   - Text: "Secure login with JWT session persistence"

3. Task list overview
   - Visual: Show the main tasks screen with a populated list.
   - Text: "Track all tasks in one place"
   - Highlight: All, Pending, Completed tabs

4. Create a task
   - Visual: Open the create task flow and add a new task title and description.
   - Text: "Add tasks quickly"

5. Edit and complete
   - Visual: Edit an existing task and mark it completed.
   - Text: "Update progress with one tap"

6. Attach a file or image
   - Visual: Show the attachment flow for a task.
   - Text: "Attach files and images"

7. Refresh and empty state
   - Visual: Show pull-to-refresh and an empty state if available.
   - Text: "Built for a smooth user experience"

8. Closing frame
   - Visual: App logo or title with a final clean dashboard shot.
   - Text: "Task Tracker App"
   - Subtext: "Expo React Native frontend, Node.js and MongoDB backend"

## Suggested Voiceover
"Task Tracker is a full-stack mobile app for managing daily work. Users can sign up, log in, create and update tasks, attach files, and switch between all, pending, and completed views. Sessions stay secure, and the experience is fast and simple across mobile devices."

## AI Video Prompt
Create a polished mobile app demo video for a task management application called Task Tracker. Show a user signing up, logging in, viewing tasks, creating a new task, editing a task, completing a task, and attaching an image or file. Highlight the All, Pending, and Completed tabs. Use smooth transitions, crisp mobile UI closeups, modern product-demo pacing, and on-screen captions. Keep the visual style clean, professional, and app-store ready.
